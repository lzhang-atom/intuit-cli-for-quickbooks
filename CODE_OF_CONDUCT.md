# Code of Conduct

Open source projects thrive on diverse perspectives and contributions. This Code of Conduct outlines the standards we expect from everyone who participates in this project.

## The Code

At Intuit, we foster an open, welcoming, and inclusive community. We ask that all participants:

- **Be kind and respectful** to one another
- **Act as a global community** by being considerate of people from different backgrounds and perspectives
- **Conduct ourselves professionally** in all interactions

The following behaviors are not acceptable:

- Violent threats or language directed against another person
- Discriminatory or derogatory jokes and language
- Public or private harassment of any kind
- Other conduct which could reasonably be considered inappropriate in a professional setting

## Scope

This Code of Conduct applies to all Intuit-managed open source repositories and community spaces associated with this project, including issues, pull requests, and discussions.
